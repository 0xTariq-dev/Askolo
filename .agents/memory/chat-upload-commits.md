---
name: Chat upload commits
description: Replit may automatically commit PNG files uploaded through chat into the active branch.
---

Chat-uploaded image files can be automatically committed as standalone asset commits, including after a history rewrite.

**Why:** A screenshot uploaded for discussion was reintroduced into the active branch after the original sensitive asset commits had been removed.

**How to apply:** Before finalizing history cleanup, check for newly created asset commits and ensure chat-uploaded image formats are ignored when they are not application assets.
