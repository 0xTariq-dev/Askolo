---
name: Askolo mark colors
description: User feedback and the chosen color behavior for the Askolo brand mark.
---

The neutral theme's branding should use its blue/mauve semantic accents for the animated initials, logo, header, and related surfaces instead of defaulting to grayscale. Keep the slogan initials distinct.

**Why:** the user asked for neutral to feel unified with the shared theme colors. A flat mask previously removed the mark's material and depth, which the user rejected.

**How to apply:** use the light/dark theme tokens for accents and color-grade the original glass artwork so its highlights, shadows, and transparency remain visible; do not replace it with a flat silhouette.
